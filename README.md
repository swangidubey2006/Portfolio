# Swangi Dubey — Professional Portfolio

Open `index.html` in a browser.

## Interaction model
- Project cards organically morph their border radius automatically on hover.
- Clicking a project card triggers a 360° Y rotation plus an AI glow/scale effect. Code/Live controls remain normal links/buttons.
- Other interactive cards receive a click pulse/glow.
- The hero uses an SD monogram instead of a profile photo; clicking SD makes it wiggle.
- Dark/light theme persists using localStorage.
- Contact form opens the visitor's email client addressed to swangi.dubey2006@gmail.com.

## Important
A `localhost` URL only works on the computer running that local server. For recruiter-facing Live Demo buttons, use a public HTTPS deployment URL.
